# Substack Portfolio Draft Playbook

Use this when turning a landing-page block or portfolio case study into a Substack draft.

## Goal

Create an original, useful article that proves Salmen Khelifi's engineering expertise and sends qualified readers to `https://www.khelifi-salmen.com/`.

## Source blocks that work

Choose one focused block from the portfolio, then expand it into a self-contained post:

- **Engineering proof:** Challenge → Risk → Decision → Verification. Best for a case study such as guarded AI routing, a migration, or a platform architecture decision.
- **How I work:** Discover → Architect → Build → Launch. Best for a product-delivery or engineering-process article.

Do not paste landing-page copy unchanged. Reframe it as a useful explanation with a direct answer, practical detail, and one real example.

## Draft structure

1. SEO title with the practical topic and outcome.
2. Subtitle that states the reader benefit in plain language.
3. Description field with a 140–160-character summary.
4. `In brief` section: a 40–60 word direct answer.
5. The source block expanded into headings, short paragraphs, and evidence.
6. One relevant internal Substack link when it genuinely helps the reader.
7. An `About Salmen Khelifi` section with one natural portfolio link.

## Portfolio backlink pattern

Use descriptive anchors, not keyword-stuffed links:

```html
<a href="https://www.khelifi-salmen.com/">software engineering portfolio</a>
```

Add one optional relevant deep link, for example:

```html
<a href="https://www.khelifi-salmen.com/projects/anlingo">Anlingo AI writing platform case study</a>
```

## Substack workflow

1. Open `https://salmenkhelifi.substack.com/publish/home` while signed in.
2. Create → Article.
3. Fill title, subtitle, and description.
4. Paste the article as rich text so headings and links remain intact.
5. Verify the live editor has the intended headings and portfolio links.
6. Refill the description field and tab out after the body has saved; the editor may clear an earlier description entry while it initializes.
7. Click **Exit** to keep the post as a draft. Do not click **Continue** or publish unless explicitly approved.
8. Confirm the title appears in the dashboard's Drafts list.

## SEO and AI-search guardrails

- Write for people first; clear headings and self-contained paragraphs also help AI search engines extract the content.
- Use genuine first-hand evidence. Do not add unsupported metrics, fabricated results, or generic AI-search filler.
- One to three natural portfolio links are enough. More links do not guarantee rankings and can make the article look promotional.
- Drafts are not indexed. A portfolio backlink can help only after the post is published and crawled.
- Publishing requires explicit approval.

## Proven draft templates

### Engineering proof

**Title:** How I Build [Outcome]: Challenge, Risk, Decision, Verification

**Sections:** In brief → Challenge → Risk → Decision → Verification → Reusable pattern → About the author

### Delivery process

**Title:** How I Deliver [Outcome]: Discover, Architect, Build, Launch

**Sections:** In brief → Discover → Architect → Build → Launch and improve → Why this process works → About the author
