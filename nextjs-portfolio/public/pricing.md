# Project Engagement & Discovery Process — Salmen Khelifi

> Every project built by Salmen Khelifi is custom-engineered. There are no fixed, public price lists or standard tier packages. All engagements follow a consultation and project contract model.

## How to Hire & Engage

### Step 1: Book a Discovery Call
All potential clients start by booking a 30-minute consultation call. During this call, we discuss your project goals, technical requirements, timeline, and budget context.
- **Book Call**: [https://cal.com/salmen-khelifi/30min](https://cal.com/salmen-khelifi/30min)

### Step 2: Technical Advisory & Scoping
Following the call, Salmen provides initial architecture recommendations, feasibility insights, and options tailored to your specific goals (whether for an n8n automation pipeline, Next.js web application, or Flutter mobile app).

### Step 3: Proposal & Project Agreement Contract
If both parties agree to move forward, a formal project proposal and contract agreement are created, defining clear deliverables, milestones, scope, and payment schedule.

---

## Engagement Types Supported
- **Full Project Build & Launch**: Custom contract for end-to-end development of web apps, mobile apps, or automation infrastructure.
- **Retainer / Fractional Engineering**: Ongoing monthly agreement for systems maintenance, automation support, and feature development.
- **Technical Consultation & Code Review**: Advisory sessions for architecture review or server troubleshooting.
