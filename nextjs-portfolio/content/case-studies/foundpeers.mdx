## Build Log

Thirty days, solo. The interesting part of this project is not any single
feature — it is that a security-tested product with a real backend got built in
a month, and that the schedule below is reconstructed from git history rather
than from memory.

<TechnicalNote>
  The same-Wi-Fi rail ships with a deliberate constraint: café and hotel
  networks frequently enable client isolation, which silently blocks the
  multicast traffic discovery depends on. So the rail only ever appears when it
  finds peers. It never renders an empty state promising something the network
  cannot deliver.
</TechnicalNote>
